# NeuroBot

A Geode mod for Geometry Dash. A neural network learns to play the level, and you can watch the network think in the corner of the screen.

- 30 small networks take turns; after each generation the 5 best are mixed and changed to make the next ones.
- The network sees the nearest spikes and blocks ahead and decides whether to jump.
- Settings: turn it on or off, show or hide the picture, game speed (faster learns faster).

Get the latest `luishae07.neurobot.geode` from the Releases page and put it in your Geode `mods` folder.
